# 🧠 DN Labs & P-PCs | Shortest Path Finder Between PCs in Labs

Welcome to **DN Labs & P-PCs** — a terminal-based project I built while exploring **Linked Lists**, where I unknowingly stepped into the world of **Graphs and Shortest Path Algorithms**! 🔍💻

This project calculates the **shortest distance between two user-selected PCs** located across multiple labs, using a data structure I originally designed as a Linked List. Later, I realized I had naturally implemented a **graph traversal algorithm** — a moment that truly sparked my love for **Data Structures & Algorithms**!

## 🚀 Project Description

### 🏢 Scenario:
- Imagine a network of **Labs**, each containing **multiple PCs**.
- The user selects **two PCs**, and the program finds the **shortest path** (in terms of distance or steps) between them.
- The program works via a **CLI (Command Line Interface)** and allows:
  - Creating Labs and PCs
  - Linking PCs (like network cables or connections)
  - Selecting source and destination PCs
  - Calculating the shortest path between them

---

## 🛠️ Features

- 📚 Structured data using **custom Linked List & Graph logic**
- 🧭 Dynamic path-finding between any two PCs
- 📈 Clean CLI-driven interface
- 🔁 Repeat queries for multiple comparisons

## 🔍 Why This Project?

At the time of building this, I was just diving into **Linked Lists** and had no idea that what I was modeling was, in fact, a **graph**. I was purely driven by logic, visualization, and curiosity. After learning more, I realized:

> 🌱 **I had accidentally created a graph traversal tool, implementing something similar to BFS/DFS for shortest path!**

This moment helped me **fall in love with DSA**, and this project will always remind me how **natural learning becomes when driven by building things**.
